# NOVA Ecommerce — React + Tailwind

## Included
- React Router pages: Home, Shop, Collections, New Arrivals, About
- Shared responsive header/navigation and footer
- Hero, product grid, collections, new arrivals, about section, video testimonial block
- Search overlay, mobile navigation, add-to-cart drawer, cart count
- Floating WhatsApp contact button
- Vite 6 + React plugin versions pinned to compatible versions

## Run locally
1. Install Node.js 18+.
2. Open this folder in VS Code / terminal.
3. Run `npm install`
4. Run `npm run dev`

## Customize
- Update product data in `src/data/products.js`.
- Update WhatsApp number in `.env` based on `.env.example`.
- Replace demo product images and testimonial video URL with your own media.
- The cart is currently a front-end demo. Payment checkout is not enabled in this page-separated starter; connect your backend payment order endpoint before accepting payments.

## Build
`npm run build`
